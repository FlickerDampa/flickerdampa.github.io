# flickerdampa.github.io

Portfolio of FlickerDampa, a security researcher and engineer focused on defensive tooling, digital forensics and resilient infrastructure.

**Live site:** https://flickerdampa.github.io/

Single static page in plain HTML, CSS and JavaScript, with a hand-written WebGL particle scene and no build step or framework. A Content Security Policy restricts scripts to hashes of the inline code, so any change to a script needs its hash updated.
