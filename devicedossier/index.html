Checking an office PC usually means clicking through System Information, Device Manager, winver, BitLocker settings and a stack of registry keys, then doing it all again on the next machine.

Features

Small tool. Serious detail.

Built for the person auditing ten laptops on a Friday, and for the admin rolling it out to a whole fleet.

Portable by design

One DeviceDossier.exe for Windows 10 and 11. It runs on .NET Framework 4.8, which ships with Windows, so there's nothing to install and nothing left behind.

Three report formats

A formatted Excel sheet with no Office needed, a self-contained HTML report, and structured XML with a published schema.

.xlsx.html.xml

Asset record

Add an asset tag, assigned user, location and notes at audit time, and they appear at the top of the report.

Save anywhere

Desktop, any USB drive as it's plugged in, or a local, mapped or network folder. It warns you if a folder syncs to OneDrive.

Built-in viewer

Browse every area in searchable, copyable tabs, and reopen saved XML reports from any PC to export them again.

Silent command line

Run a full audit with no window from scheduled tasks, Group Policy, Intune or an RMM tool.

Light, dark and High Contrast

Follows your Windows theme, title bar included, or choose one in Settings.

Fault-tolerant

A stuck section is marked as an error instead of freezing the whole audit.

Settings that travel with it

Set default formats, known file servers, excluded disks and time limits once. Settings save next to the exe, so they follow your USB drive, and you can export them to set up other copies the same way. Known servers let it flag mapped drives that point somewhere unexpected.

What it collects

Sixteen sections. Zero guesswork.

Everything comes straight from Windows: WMI, the registry, and the storage and display drivers, plus nvidia-smi when an NVIDIA driver is present. No third-party tools.

The reports

Readable by people. Usable by tools.

HTMLFor reading and sharing

One self-contained page with tabs, search across the whole report, sortable tables, dark mode and a print or PDF layout. Works offline in any browser.

XLSXFor inventories

One formatted sheet, written natively, so Excel isn't needed to create it. The layout is the same every time, so audits merge cleanly.

XMLFor automation

Structured data with a published schema, ready to import into other tools or reopen in DeviceDossier.

Get started

From download to dossier in minutes.

Download

Get DeviceDossier.zip from Releases and check it against SHA256SUMS.txt.

Extract

Unzip it anywhere, such as a USB drive you carry between machines.

Run

Double-click DeviceDossier.exe on the PC to audit and accept the administrator prompt.

Audit

Pick where to save and which formats, add asset details if you like, then click Run full audit.

Seeing "Windows protected your PC"? Beta builds aren't code-signed yet, so SmartScreen may warn you. Choose More info → Run anyway, or build it from source. Because the tool reads product keys, other users' profiles and browser data, some antivirus products may flag it as a potentially unwanted tool. Check the SHA-256 against the release, and report false positives to your vendor, for example through Microsoft's submission portal.

For IT teams

Audit a fleet without touching it.

The silent mode runs a full audit with no window and never prompts for elevation. Run it as an administrator or as SYSTEM for complete results.

Scheduled tasksGroup PolicyIntuneRMM toolsShared settings file

Collect every PC's audit on a share, with a log, an asset record and only the formats you need.

PowerShell
# Collect each PC's audit on a network share
& "\\server\it\DeviceDossier\DeviceDossier.exe" --silent --formats xlsx,xml --output "\\server\it\Audits\$env:COMPUTERNAME" | Out-Null

# Options
--output     folder for the reports
--formats    xlsx, html, xml or all
--settings   use a shared settings file
--skip       drives,security,patches,software,extensions
--asset-tag  plus --assigned-to, --location, --notes
--log        append progress to a log file

Trust and privacy

It looks. It never touches.

An audit tool sees sensitive data, so DeviceDossier is built to be predictable and inspectable.

Read-only

It never changes settings on the PC it audits.

Offline

It sends nothing over the network. Reports stay wherever you save them.

Keys masked

The Windows product key is masked by default. You choose whether to show it.

Safe with other profiles

Logged-off users' profiles are opened privately and read-only, so a failed read can't affect their next sign-in.

Open source

MIT licensed. Read every line on GitHub, or build it yourself.

Checked releases

Every release ships with SHA-256 checksums, and automated tests run a real silent audit on each build.

FAQ

Good questions.

Something else on your mind? Ask it on GitHub, and the answer may end up here.

Is DeviceDossier free?

Yes. It's free and open source under the MIT licence, including for use at work.

Does it change anything on the PC?

No. It only reads information, and it never changes settings on the PC it audits. Reports are written only to the folder you choose.

Does it need the internet?

No. It works fully offline and sends nothing over the network.

Which Windows versions does it support?

Windows 10 and Windows 11. It uses .NET Framework 4.8, which is already part of Windows.

Do I need administrator rights?

It asks for them at startup, but you can say no. In limited mode it still reads most things and clearly marks what it couldn't: BitLocker status, SSD wear, some battery details, TPM details, and other users' saved drives, network locations and browser extensions.

Why does Windows or my antivirus warn me about it?

Beta builds aren't code-signed yet, which triggers SmartScreen. Some antivirus products also flag tools that read product keys and browser data. Verify the download with the SHA-256 checksum from the release, and see the README for details.

Is the report sensitive?

Yes. It can include serial numbers, network addresses, user names, server paths and installed software. Only audit devices you're authorised to audit, and store reports somewhere access-controlled.
